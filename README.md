# Portfolio — Tóth Avar

A personal portfolio website for Tóth Avar, a Computer Science Engineering
student at BME (Budapest University of Technology and Economics).

It's a small multi-page site with a sleek, editorial feel: a warm palette,
high-contrast type, a slowly drifting accent color, and an animated
sacred-geometry mandala background. Light and dark themes are both supported.

## Pages

- **Home** — a brief intro and summary.
- **About** — background, toolkit, education, and interests.
- **Portfolio** — selected projects.

## Stack

Plain HTML, CSS, and vanilla JavaScript — no framework, no build step, and no
dependencies. It can be hosted as-is on any static host (GitHub Pages, Netlify,
Vercel, etc.).

## Running locally

Open `index.html` in a browser, or serve the folder for correct relative paths:

```powershell
python -m http.server 8000
# then visit http://localhost:8000
```
